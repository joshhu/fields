# 第二批素材清單

規則同第一批：只用可合法再利用的授權（公有領域 / CC0 / CC BY / CC BY-SA，例如 Wikimedia Commons、NASA、ESA、ESO、CERN CC-BY）。
圖片輸出到 `assets/img/<key>.jpg`，寬度盡量 ≥ 1400px；影片輸出到 `assets/vid/<key>.mp4`，規格是 1920x1080、30fps、h264、無聲，長度至少 12 秒，畫面上盡量不要有字。
真的找不到時可以換成意思相近的素材，但 key 不變，並在回報裡註明。
