# 動畫規格 (Manim CE, 無 LaTeX)

## 共同風格
- 1920x1080, 30fps, 無聲。輸出到 `assets/anim/<name>.mp4`。
- 原始碼放 `anims/<name>.py`，Scene class 名稱 = `Main`。
- 渲染指令（在 `anims/` 目錄下）：
  `uv run manim -qh --fps 30 --disable_caching --media_dir ../build/manim -o <name>.mp4 <name>.py Main`
  再把 `../build/manim/videos/<name>/1080p30/<name>.mp4` 複製到 `../assets/anim/<name>.mp4`。
- 背景色 `#0B1020`（深藍黑）。主色：場/波 `#4FC3F7`（青藍）、粒子 `#FFB74D`（橘）、強調 `#F06292`（粉紅）、
  次要線條 `#90A4AE`、文字 `#ECEFF1`。可共用 `anims/style.py`（先建立者負責，別人 import）。
- 中文字一律 `Text(..., font="Microsoft JhengHei")`。系統沒有 LaTeX，**不可用 MathTex/Tex**；
  數學式用 Unicode Text，例如 `∇·E = ρ/ε₀`、`∇×B = μ₀J + μ₀ε₀ ∂E/∂t`、`G_μν = 8πG T_μν`。
- 畫面底部 170px（manim 座標 y < -2.9）保留給字幕，不要放重要內容；左上角前 4 秒會疊章節標題，避免放字。
- 畫面要「一直在動」：長於 8 秒的段落避免整段靜止（用 updater、緩慢鏡頭位移、粒子漂浮、波動等）。
- 每段動畫長度 **至少** 為下表的秒數（可多 2–4 秒）。結尾不要淡出成全黑（剪輯時會做轉場）。
- 畫面上的標籤文字精簡、繁體中文台灣用語。
- 完成後抽一張中段影格（`ffmpeg -ss <t> -i x.mp4 -frames:v 1 x.png`）用 Read 看一下，確認沒有破圖、字沒被裁切。

## 清單（名稱：最短秒數｜內容）

### 第 1 組 古典場
- title：22｜片頭。深空背景緩慢飄動的粒子點，青藍色場線/波紋從中央擴散，主標題「場比粒子更基本」、副標「物理學三百年的終極轉向」淡入，最後標題縮小上移、背景波紋持續。
- action_at_distance：25｜太陽（橘大圓）與地球（藍小圓）繞轉；標出「F = G·m₁m₂ / r²」；太陽突然移動時，連線瞬間跟著改變，並出現「瞬間？」「沒有介質？」問號；手繪感虛線表示超距。
- field_lines：21｜條形磁鐵（紅 N / 藍 S），先撒上隨機鐵屑短線段，再逐漸轉向排列成偶極場線（用 StreamLines 或自算偶極場），最後場線本身發亮流動，標註「力線」。
- maxwell_eq：22｜四條馬克士威方程以 Unicode 逐條寫出：高斯定律 ∇·E = ρ/ε₀、∇·B = 0、法拉第定律 ∇×E = −∂B/∂t、安培－馬克士威 ∇×B = μ₀J + μ₀ε₀∂E/∂t，每條旁標中文名稱；最後推導出 c = 1/√(μ₀ε₀) 並亮起「＝ 光速」。
- em_wave：22｜3D 電磁波：E 場（青藍箭頭/正弦）與 B 場（粉紅）互相垂直沿 x 軸傳播，鏡頭緩慢旋轉；再切換到 2D：一個電荷 A 抖動，同心圓波以有限速度擴散，傳到 B 時 B 才開始動，標「以光速傳播」。
- michelson：17｜邁克生干涉儀示意：光源、分光鏡、兩臂鏡子、偵測器；光束動畫往返；旁邊「以太風？」箭頭；最後干涉條紋不變，打上「光速各方向都一樣」。
- spacetime：24｜扭曲的網格（3D 曲面或 2D 透視網格）：中央重物使網格下凹，小球沿凹陷繞轉、滾入；鏡頭緩慢移動；標「質量彎曲時空」「時空告訴物質如何運動」，最後顯示 `G_μν = 8πG T_μν`（愛因斯坦場方程式）。
- negative_energy：22｜能階圖：E=0 上方正能態、下方負能態延伸到 −∞，電子一直往下掉的動畫（問題）；接著填滿「狄拉克海」，打出一個電洞→標示「正電子 e⁺」。
- pair_creation：17｜光子（波浪線）撞擊後變成電子 e⁻ 與正電子 e⁺ 分開；另一側 e⁻ 與 e⁺ 相遇湮滅成兩個光子；計數器顯示「粒子數：1 → 2 → 0」。
- harmonic_modes：17｜一個盒子裡的駐波模式 n=1,2,3（弦振動），每個模式旁邊一個量子諧振子能階梯子，能階上升一格時冒出一個光子圖示，標「一個量子 = 一個光子」。

### 第 2 組 量子場
- quantum_field：22｜3D 曲面（或密集點陣）代表瀰漫空間的量子場，表面有微弱真空漲落；某處鼓起一個局域波包（亮橘），沿表面移動 = 粒子；標「粒子 = 場的激發」。
- field_ocean：19｜平靜海面（2D 剖面或 3D 曲面），隨機位置濺起浪花（波包）後消散；標「場：大海」「粒子：浪花」。
- beta_decay：19｜四條水平「場」線（中子場、質子場、電子場、微中子場），中子場上的波包消失，同時質子、電子、反微中子場各自冒出波包；上方寫 n → p + e⁻ + ν̄ₑ。
- infinity：20｜電子自能示意：電子周圍虛光子迴圈越來越多，計算式各項 1 + α + α² ... 旁的數字飆升成「∞」，紅色閃爍；然後「重整化」：把 ∞ 收進「m₀、e₀」盒子，輸出有限的「m、e（實驗值）」。
- feynman_diagram：20｜逐步畫出費曼圖：兩電子交換虛光子（時間軸向上）、再畫電子自能迴圈圖、真空極化圖；標「每張圖 = 微擾展開的一項」。
- block_spin：23｜伊辛模型格點 (例如 128×128 黑白像素，用 numpy 或 Metropolis 生成臨界態)，逐步 2×2 區塊平均粗粒化：128→64→32→16，每步放大顯示；標「粗粒化：細節被洗掉，輪廓留下」。
- rg_flow：23｜重整化群流：二維參數平面上許多流線箭頭流向一個不動點（亮點），從「高能量」到「低能量」；不同起點（標流體、磁鐵、合金）流向同一點，標「普適性」。
- nested_theories：23｜同心圓（或俄羅斯娃娃）由內而外：牛頓力學 ⊂ 狹義相對論 ⊂ 廣義相對論 / 量子場論 ⊂ ？（更深層理論），一層層擴張出現。
- gauge_symmetry：19｜左：U(1) 一個圓上的相位箭頭，兩次旋轉順序交換結果相同（可交換）；右：SU(2) 球面上兩次旋轉順序交換結果不同（不可交換）；標「阿貝爾」「非阿貝爾」，最後出現「楊－米爾斯理論 1954」。
- pencil：17｜鉛筆立在桌面（俯視+側視），對稱的各方向箭頭，然後倒向某個方向，標「自發對稱性破缺」。

### 第 3 組 現代物理
- mexican_hat：17｜3D 墨西哥帽位勢曲面，小球從中央頂端滾落到谷底某處；鏡頭環繞；標「希格斯位勢」「真空選定一個方向」。
- standard_model：17｜標準模型粒子表（4×4 夸克/輕子/規範玻色子 + 希格斯），逐格亮起，上方顯示 SU(3) × SU(2) × U(1)，三個群各自對應「強作用 / 弱作用 / 電磁（電弱）」顏色框。
- symmetry_logic：16｜兩條流程對比：上「牛頓：觀察力 → 寫方程式」；下「規範場論：指定對稱性 → 拉格朗日量 → 交互作用」，箭頭逐步出現，最後下方流程發亮；附「諾特定理：對稱性 ⇔ 守恆律」。
- hawking_radiation：19｜黑洞（黑圓 + 事件視界發光環），視界附近不斷出現虛粒子對，一個掉入、一個逃逸成為輻射；黑洞慢慢變小；標「霍金輻射」。
- unruh：19｜左右分割：左「慣性觀察者」看到空白真空；右「加速觀察者」（火箭）周圍出現熱粒子雲；中間同一片場的波動相同；標「粒子取決於觀察者，場是客觀的」。
- four_reasons：65｜四大理由逐條出現並各有小動畫（每條約 14 秒）：①超距作用說不通（兩點間波以有限速度傳遞）②相對論量子力學不自洽（粒子產生湮滅）③交互作用的統一（三個力合流成 SU(3)×SU(2)×U(1)）④局域對稱性（每個格點上的箭頭各自旋轉，需要規範場連接）。最後四格同框，標題「場論：唯一自洽的框架」。
- string_modes：16｜一條閉弦/開弦以不同模式振動（n=1,2,3），每種振動旁標「不同粒子」；標「弦論」。
- lattice：16｜3D/2D 格點時空：連續空間被切成晶格，格點上有箭頭、連線（link）顯示規範場，標「晶格 QCD」。
- outro：17｜回顧時間軸：1687 牛頓、1830s 法拉第、1865 馬克士威、1905/1915 愛因斯坦、1927 量子電動力學、1954 楊－米爾斯、1973 標準模型、2012 希格斯，逐一點亮；最後中央顯示「空間，才是宇宙真正的主角」。
